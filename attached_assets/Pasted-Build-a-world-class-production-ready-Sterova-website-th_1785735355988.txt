Build a **world-class, production-ready Sterova website** that feels premium, modern, fast, and enterprise-grade.

This is **not** a basic brochure site. It must be a polished business platform that builds trust, generates leads, supports SEO, and positions Sterova as a serious software company.

---

# Core instruction

Before writing any code, first create:

1. A **clear implementation plan**
2. A **feature-by-feature task list**
3. A **strict execution order**
4. A **definition of done** for each feature

Then implement the website **one feature at a time**, in order, and **do not move to the next feature until the current one is fully implemented, polished, tested, and integrated properly**.

Do **not** partially build multiple features at once.
Do **not** rush through features.
Do **not** skip quality.
Do **not** continue to the next task until the current one is complete and best-in-class.

---

# Required website pages and structure

## 1) Home

The landing page must answer these questions within 5 seconds:

* What is Sterova?
* Who do you help?
* Why choose Sterova?
* What should the user do next?

The page should include:

* Hero section
* Trusted technologies
* Services overview
* Featured projects
* Testimonials
* Development process
* Statistics
* FAQ preview
* Contact CTA
* Strong primary CTA: **Start Your Project**

---

## 2) About

**Do not use About as a dropdown.**
Show **About as one top-level navbar link** only.

All About content should live inside the About page itself.

Include:

* Company story
* Mission
* Vision
* Core values
* Why Sterova exists
* Company timeline
* Team section if appropriate
* Why choose Sterova
* A strong credibility section
* CTA to contact or view services

Make it feel complete, human, and polished in one page.

---

## 3) Services

Create a strong overview page that displays all services as elegant cards.

Each service card must link to its own dedicated SEO-friendly service page.

Example services:

* Web Development
* Mobile Apps
* UI/UX Design
* API Development
* Maintenance & Support

The services page should feel premium, visual, and easy to scan.

---

## 4) Individual Service Pages

Create separate SEO-friendly pages such as:

* `/services/web-development`
* `/services/mobile-development`
* `/services/ui-ux-design`
* `/services/api-development`

Each service page must include:

* Overview
* Who this service is for
* Benefits
* Technologies used
* Development process
* Pricing approach
* FAQ
* CTA

Do not crowd everything onto one page.

# Implementation rules

## Build sequentially

You must:

1. Create a plan
2. Break into tasks
3. Implement one feature fully
4. Test and verify it
5. Polish it
6. Only then move to the next feature

## No parallel unfinished work

Do not leave multiple major features half-done.

## No low-quality placeholders

Do not ship weak stub pages unless absolutely necessary for scaffolding, and mark them clearly if temporary.

## Keep consistency

The entire site must share the same design system, spacing, typography, and branding logic.

## Prioritize quality

Every page should feel deliberate, premium, and production-ready.

## Keep SEO in mind

Use clean routes, strong metadata, semantic structure, and content that can rank.

## Keep mobile-first responsiveness

Everything must work beautifully on mobile, tablet, and desktop.
